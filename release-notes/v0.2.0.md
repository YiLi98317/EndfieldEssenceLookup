# v0.2.0 — Desktop app and automated releases

This release ships the same lookup experience as the website in a standalone desktop app, and automates future GitHub Releases.

## Downloads

- **macOS**: Download the `.dmg`
- **Windows**: Download the `.exe`

Install, then use the app offline the same way as [the web version](https://yili98317.github.io/EndfieldEssenceLookup/).

## Changes since v0.1.2

- Packaged Electron app loads the built UI from inside the installer (no local web server)
- Fix asset paths so the desktop build works with the GitHub Pages `/EndfieldEssenceLookup/` base URL
- Simplify local commands: `npm run dev` (web), `npm run dev:desktop` (window + Vite), `npm run dist` (installers)
- **CI/CD**: merging a PR labeled `release` plus `patch` / `minor` / `major` bumps the version, tags, writes the GitHub Release from `release-notes/vX.Y.Z.md`, and builds macOS `.dmg` and Windows `.exe`
- Feature PRs without those labels still only update GitHub Pages

## Notes

- macOS builds are **not signed/notarized** yet (Gatekeeper may warn on first open; use right-click → Open).
- Do not bump `package.json` or push tags by hand; the merge workflow does that.
